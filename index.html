FOUND THIS

FOUND THIS is an owner-operated media automation application that researches, creates, publishes and analyses original short-form content for the owner's FOUND THIS YouTube channel.

What FOUND THIS does

FOUND THIS automates routine content generation and publishing within controls defined by the owner. It operates only on the owner's own YouTube channel and is not a public SaaS product.

Why FOUND THIS uses YouTube APIs

With the owner's permission, FOUND THIS uses YouTube API Services to:

  • upload videos created by the FOUND THIS content engine;
  • read the owner's channel and video information needed for publishing and monitoring; and
  • retrieve YouTube Analytics data so the application can measure performance and improve future content decisions.

FOUND THIS does not sell or share Google or YouTube user data. Its use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.
