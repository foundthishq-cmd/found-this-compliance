About the Content Engine

FOUND THIS Content Engine is a private, owner-operated desktop tool that researches useful subjects, creates original short-form videos and helps publish them to the owner's channels.

YouTube API use

With the owner's permission, the tool uses YouTube API Services to upload original videos to the owner's own channel, confirm processing and privacy status, and retrieve non-monetary performance analytics for a local learning process. It does not provide access to other creators and is not a public software service.

Use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.
